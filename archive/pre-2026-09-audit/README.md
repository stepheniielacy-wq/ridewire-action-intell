# Archive: pre-2026-09 speculative files

These 64 files were sitting at the repo root before the September 2026 honesty audit.
They are strategy documents, pitch decks, letters, and plans written in an earlier phase
of this project — several describe RideWire as "production-ready," "launch-ready SaaS,"
or fully built when it was not, and some (equity plans, personal letters) were never
meant to be public-repo artifacts in the first place.

They are kept here for history, not deleted, but **none of them should be treated as
current, verified, or true** unless a specific claim in them has been independently
re-checked against real, working code or sourced research (the way the motorcycle job
aids in `/job_aids/motorcycle/` were).

If you want to resurrect an idea from one of these files, treat it as a fresh proposal
to validate — not a finished thing to reference as fact.
